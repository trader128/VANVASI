VANVASI 1.1 — Notes for App Review
===================================

VANVASI is a self-imposed digital wellbeing app for adults (not parental monitoring).

WHAT'S NEW IN 1.1:
- Expanded onboarding and in-app "How it works" guide
- Clearer Settings with descriptions
- Improved block screen (shield) branding

HOW TO TEST:
1. Complete onboarding — grant Screen Time when prompted.
2. On "Free apps", select Phone, Messages, and VANVASI.
3. Tap the lock ring → monk mode ON.
4. Open Safari or another app → shield with Pause / Unlock.
5. Tap Unlock → complete pause flow in VANVASI.
6. Settings (⋯) → How it works for full guide.
7. End lock: Settings → End lock.

PRICING: App is free. No payment required for core features.

EMERGENCY EXIT: Settings → End lock. Optional PIN available.

CONTACT: support@vanasi.app
